Casting — Find the Faces

5 variations per character. Same costume, same design — different person wearing it. Like a casting call.

Engine Writes 5

5 landscape portraits per character. Different face, build, age, energy. Same costume + signature detail locked.

→

You Generate

5 images in your tool. 16:9 landscape. White background. Neutral lighting. This is a casting call, not a photoshoot.

→

Pick Your Cast

Select one face per character. "That's Mara." "That's Jude." The cast is locked.

→

Prompt Anchor

Engine writes a 30-50 word description of the selected face. This EXACT text gets pasted into every future prompt.

→

Consistency

From now on, "Mara" in any scene = the same face, same build, same scar, same everything. Hundreds of images. Same person.

How Consistency Works Across Hundreds of Images

Character Prompt Anchor

Locked after casting. Pasted verbatim into every prompt that includes this character.
Mara Voss: Weather-lined woman, early 40s, deep-set dark eyes, broken nose healed crooked, sun-darkened angular face, lean muscular build. Worn leather duster, bone-spur clasp at collar, dust in cropped grey-streaked hair.

Location Prompt Anchor

Locked after location design. Pasted verbatim into every prompt set in this place.
The Bonefield: Narrow canyon, exposed fossil walls in stratified red-ochre sandstone, dinosaur ribcages embedded in cliff face, cracked dry riverbed floor, dawn light raking horizontally across east-facing wall, dust suspended in amber shafts.

Set Sheet Prompt Block

Locked after settings. Every physical object in the space — no improvising.
Mara's camp: Canvas lean-to against canyon wall, fire pit with iron grate, tin coffee pot (dented, blackened base), coiled hemp rope on sandstone ledge, saddle on ground with bone-spur pommel, single wool blanket (grey, frayed edge).

Scene Template

Built per scene. Locked blocks identical across all 10 prompt variations. Only camera/lens/light vary.
Locked: Format + Medium + Environment + Character + Negatives Variable: Camera angle, lens focal length, DOF, which light source dominates Result: 10 different camera angles of the same moment. All cut together. Any combination works.

Shot Generation — The Production Cycle

This is where the bulk of image generation happens. For each curated scene: decompose into shots, build the Scene Template, generate 10 prompt variations per shot, generate images, select the best.

Scene Template

Engine builds locked blocks from Prompt Anchors + Set Sheets + VLD. Only camera/lens/light will vary.

→

Shot Table

Scene decomposed into 3-8 shots. Each shot is a different moment/angle. Designed as an edit — they must cut together.

→

10 Prompts Per Shot

JSON prompts. Each varies camera angle, lens, light emphasis. Same locked character + environment. You generate all 10.

→

Select Best

Review generated images. Pick the strongest from each shot. Mix and match — 1a cuts with 2c cuts with 3f.

→

Motion

Selected stills get video prompts — camera movement + subject action + environment motion. Generate in Runway, Kling, etc.

Per scene: 3-8 shots × 10 prompts = 30-80 images generated Per IP: 20-40 curated scenes = 600-3,200 images generated Consistency: Same character face, same location, same props across ALL of them
Alt Path — Short-Form (branches at any point)

Short-Form — Viral Content Pipeline

Branches from Stage 1 (standalone concept) or from a completed IP (inherits all locked visual data). Motion only — no stills.

Find the Angle

15 creative angles run against the concept. The Wrong Detail, The Pull-Back, The Document, The Face... 1-2 fire.

→

Pick Format

Loop (3-5s), Punch (5-15s), Carousel, Micro-Trailer, or Character Intro. The angle dictates the format.

→

Concept Lock

Angle + format + viral mechanics + copy. Everything decided before any generation. No prompt without a locked concept.

→

Generate

Video prompts by format. If post-pipeline: Prompt Anchors pasted verbatim for character/location consistency.

→

Distribute

9:16 vertical. Works muted. Hook in frame 1. Platform-agnostic but scroll-native.
