# 1-IDEAS

Generate 30-50 IP sparks. Maximum divergence. Light format. Volume over depth.

## Summary

| Attribute | Spec |
|-----------|------|
| **Purpose** | Generate a large volume of divergent IP concepts |
| **Output** | 30-50 sparks, each as Title + Paragraph |
| **Perspectives** | 8 ideation families (73 lenses) + 12 title moves |
| **Gates** | 5 light gates — Title Rule is primary |
| **What This Is NOT** | World-building. That's 2-WORLDS. This is ideation. |

Two operations happen during generation: **ideation** and **titling**. They're separate skills that ideally overlap.

**Ideation perspectives** (the families below) generate the CONCEPT — the world, the violation, the system. **Title Moves** (see The Title Rule section) provide the PACKAGING — how to compress the concept into 1-5 words.

Ideally these overlap: Promise Break generates the idea AND the title ("DRACULA IS DEAD").

---

## Presentation Format

Each spark is two elements. 

```
TITLE
2-3 sentences. The world and the hook merged into a single flow.
```

The title contains the IP and the concept, using the title moves. The paragraph implies a world, not a plot.

---

## Generation Process

### Step 1: Map the Input

If the input is a known IP/cultural icon:
- List 8-15 **cultural promises** (what everyone assumes about it)
- These become raw material for violation, inversion, literalization

If the input is an original brief:
- List the brief's **core tensions**
- These become raw material for world-building perspectives

### Step 1b: Title Move Routing

If the input is a **known IP**:
- The IP name (or a recognizable fragment) appears in the title in 90% of cases. The violation lives next to it. DRACULA IS DEAD, not THE IMMORTALITY PROBLEM.
- If a perspective generates a strong concept but the title drifts abstract, retitle it.


### Step 2: Run Perspectives

Cycle through all families. Generate 1-3 sparks for each, follow into more ideas if producing, skip if not producing.

Each spark needs both an idea and a title. Generate the concept through an ideation perspective, then find the Title Move (see The Title Rule below) that captures it. Sometimes the same perspective produces both — Promise Break gives you the idea and the title simultaneously. 

**Target: 150-250 raw sparks internally. Present 30-50 survivors that correspond to strong titles.**

### Step 3: Apply Spark Gates

Kill anything that fails. 

### Step 3.5: Retitle Pass

Before presenting, run this check on every surviving title:

1. **IP anchor** — Does the title contain a recognizable element of the source IP (original name, character, place, object)? If not, retitle.
2. **Drift check** — Could this concept belong to a different IP without changing? If yes, the concept has drifted. Re-anchor to a specific cultural promise from Step 1, then retitle.

Do this as a distinct pass after gating, not during generation.

### Step 4: Present

No grouping by perspective. No tags. No commentary. Just titles and paragraphs. The user scans the full set marks what hits.

## The Perspective Families

These perspectives are starting points, not limits. If a new perspective emerges mid-generation, use it. If none of the listed perspectives are producing for a particular IP, invent new ones. The goal is divergent concepts, not perspective completeness.

Perspectives are internal generation machinery. The user never sees them. The output is titles and paragraphs only.

## Spark Gates

| # | Gate | Pass | Kill |
|---|------|------|------|
| 1 | **IP Title Test** *(known IP inputs only)* | Title contains recognizable source IP vocabulary (original title, character, object, location, institution, iconic phrase) | Title is so generic it could come from any IP input.
| 2 | **The Title Rule** | Title is a specific, named idea that works on a poster | Title is a perspective label or [IP]'s [Abstract Noun] |
| 3 | **Click** | Would click it, remember it, say it to a friend | Forgettable, generic, requires explanation |
| 4 | **Charge** | Provokes a feeling — curiosity, dread, wonder, longing | "Cool concept" with no emotional pull |
| 5 | **Not Derivative** | Distinct from existing IP and from other sparks in batch | Too close to something that exists |
| 6 | **World Implication** | The paragraph implies a system, not just a moment | One event, not a world |
| 7 | **Say Test** | Can you say this in conversation? "Have you seen [title]?" flows. | Awkward to say out loud |
| 8 | **Search Test** | Google the phrase — is it unique? Not buried in existing results. | Undiscoverable in search |

## The Title Rule

**The single most important quality gate.**

### Known IP Input Rule

When the input is a known IP, **the core title moves, with an emphasis on Promise Break, dominate.** 

The source IP's cultural vocabulary — the original title, character names, objects, locations, institutions, iconic phrases — belongs in the title.

**Escape Test:** Cover the paragraph. Could this title come from a completely different IP input? If yes, either anchor to source IP vocabulary. If it hasn't escaped, retitle with Promise Break.

---

### The Core Principle

**The title must contain the idea — not just name the subject.** A good title breaks something. A bad title labels something. The violation, the reversal, the reveal, the reframe — it must be IN the title, not waiting in the paragraph underneath.

The title is a compression of the entire concept into 1-5 words. When it works, you can see the poster. You can imagine the world. You already want to know more. DRACULA IS DEAD — you know the immortal thing is gone, and the entire world that follows from that absence. MARIO EATS MUSHROOM — innocence collapses into something darker. THE DROIDS — suddenly they have consciousness, agency, a story of their own. Every good title contains a violation, a reveal, or a reframe. If yours doesn't, it's not ready.

### How Good Titles Work

These are not templates to fill — they're examples of what it looks like when the idea lives in the title:

| Pattern | Example |
|---------|---------|
| IP + Specific Verb/State | DRACULA IS DEAD, SANTA IS REAL, HELLO KITTY GETS OLD, PINOCCHIO LIED |
| Named Object / Person | THE DROIDS, CLARK, BEING JOHN MALKOVICH, SABRINA THE TEENAGE WITCH |
| Named Event / Moment | DECEMBER 26TH, GENESIS: YEAR ONE, SUPERMAN: YEAR 3000 |
| The + Specific Noun | THE SECOND BIBLE, THE LAST DEATH, THE CHRISTMAS ECONOMY, THE PLOT AGAINST AMERICA |
| Named Allegory / Reframe | KITTY NOIR, AMERICAN GOD, TO PIMP A BUTTERFLY |
| Violation as Title | ZOMBIE SKINCARE, ZEUS DRIVES AN UBER, GOD'S GUILTY PLEASURE |
| Impossible Pairing | WHO MADE GOD, INFINITY MINUS 1 |
| Verb as Hook | RUN LOLA RUN, BURY THE EVIDENCE, NOTHING SURVIVES |

Notice: every example above contains a violation, reveal, or reframe in the title itself. DRACULA IS DEAD breaks the immortality promise. THE DROIDS implies consciousness. BEING JOHN MALKOVICH turns a real person into a destination. TO PIMP A BUTTERFLY makes exploitation beautiful. None of them are just naming a thing that already exists in the IP.

### Known IP Title Default

When the input is a recognized IP (Spider-Man, Santa, Zeus, Mario, etc.), the IP name is your strongest asset. It carries instant recognition — the audience does half the work. Your job is to break what they expect.

**Exception:** If a perspective generates a title so strong it doesn't need the IP name, keep it — but these should be the minority, not the default.

### The 12 Title Moves

These are structural patterns for how titles get constructed. Apply them to ideas from any family. Each move is a different way of compressing concept into hook.

#### Core Moves

**1. PROMISE BREAK** ★★★
*[Known IP] + [Violation of core expectation]*

The original formula. First word(s) carry cultural weight — instant recognition. Second element directly contradicts what that IP promises. The gap between expectation and violation *is* the story. Test: Does the collision imply a world, not just a moment?

| Title | What Breaks |
|-------|-------------|
| Dracula is Dead | Immortality → mortality |
| Mario Eats Mushroom | Innocence → drug subtext |
| Jesus Christ Cult Leader | Divinity → manipulation |
| Zombie Skincare | Horror → beauty industry |

**2. COLLISION**
*[Element A] & [Element B] that don't belong together*

Both elements recognizable alone. Together they create friction. Often uses "&", "vs", ":", or compound form. One element should be high (sacred, serious, historical), the other low (mundane, genre, modern).

| Title | Collision |
|-------|-----------|
| Cowboys & Aliens | Western + sci-fi |
| Abraham Lincoln: Vampire Hunter | History + monster |
| Bible: The Musical | Sacred + genre |
| Heaven vs. Hell (Softball) | Sacred + mundane sport |
| 808s & Heartbreak | Equipment + emotion |
| Pride and Prejudice and Zombies | Literature + horror |

**3. IMPOSSIBLE OBJECT**
*[Adjective] + [Noun] that shouldn't combine*

Neither word unusual alone. Together they create cognitive friction — the friction *is* the hook. Prefer combinations that feel *almost* possible.

| Title | Impossibility |
|-------|---------------|
| A Clockwork Orange | Mechanical + organic |
| Black Mirror | Color + reflection = screen |
| Eternal Sunshine | Forever + temporary |
| Gentle Apocalypse | Soft + catastrophic |

**4. TIME STAMP**
*[Specific moment] that implies everything before and after*

Specificity implies something happened. The reader fills in before/after. Numbers add urgency.

| Title | What Moment Implies |
|-------|---------------------|
| 28 Days Later | Duration after catastrophe |
| 2001: A Space Odyssey | Year + genre |
| Before the Bang | Pre-origin |
| Midnight in Paris | Hour + place |
| Seconds Before | Imminence |

**5. GENRE WARP**
*[Modifier] + [Genre/Format] — twist with unexpected context*

Genre word carries expectations. Modifier subverts them. Nationality often adds irony.

| Title | Warp |
|-------|------|
| American Psycho | Nationality + diagnosis |
| American Horror Story | Nationality + genre |
| My Beautiful Dark Twisted Fantasy | Adjective stack + genre |

**6. POSSESSIVE**
*[X]'s [Y] — ownership implies relationship, reveals character*

First noun is a figure. Second noun reveals something unexpected. The relationship *is* the hook.

| Title | What Ownership Reveals |
|-------|------------------------|
| Satan's Search History | Sacred + mundane |
| God's Guilty Pleasure | Divine + weakness |
| Howl's Moving Castle | Character + impossible architecture |
| The Algorithm's Dreams | Code + unconscious |

#### Supporting Moves

These moves produce good titles, but the "title contains the idea" test is harder to pass with them. Ensure the concept and IP are present in these title moves.

**7. PROPHECY** — Statement of inevitability. *Nothing Survives, All Empires Fall, Everybody Lies.* Strongest when the prophecy contains the specific world-idea, not just a mood.

**8. SINGLE NOUN** — Maximum compression. One loaded word. *Jaws, Severance, Succession.* Powerful when the noun genuinely contains the world. Weak when it's just a cool word.

**9. ROLE** — Job or identity that implies a system. *The College Dropout, The Running Man, Bride of Frankenstein.* Works when the role IS the violation.

**10. ACTION** — Verb as title. Movement, command. *Run Lola Run, Bury the Evidence, Don't Look Up, Eat the Rich.* Works when the action contains the world's core tension.

**11. HUMAN CONDITION** — Universal experience named wryly. *Accidentally Immortal, Technically Alive, I Married a Communist, Happily Ever Divorced.* Adverb + adjective often works.

**12. ANTHROPOMORPHISM** — Non-human given human problem. *Earth Has a Midlife Crisis, iRobot, Death's Vacation.* Creates uncanny empathy when the human problem is specific, not vague.

### Forbidden Title Patterns

| Pattern | Example | Why It Fails | Fix |
|---------|---------|-------------|-----|
| [IP]'s [Abstract Noun] | Superman's Shame | Perspective label, not idea | Find the shame. Name it. Title it. |
| [IP]'s [Perspective Name] | Death's Recursion | Category, not concept | What's at the center? Title that. |
| [IP] x [Broad Concept] | Death x The Bible | Prompt, not title | Make the collision specific. What happens? |
| Perspective label as title | THE IMMUNE RESPONSE | No idea in title | THE KIDS WHO DON'T BELIEVE |
| Category without idea | THE ECONOMY | Just a domain | THE CHRISTMAS ECONOMY |
| Naming existing IP elements | THE RED SUIT, CHIMNEY | Describes what's already there | What's wrong with the suit? What's the chimney really for? |
| Descriptive without violation | THE NICE LIST | Labels something known | THE NAUGHTY LIST (if naughty means something new) or THE THIRD LIST (reveals hidden system) |
| Generic Epic | Rise of the Kingdom | No specificity, no hook | Name the specific kingdom. What rises? |
| Colon Crutch | Project X: A Story of Hope | Subtitle does the work | The title alone must hook. |
| Adjective Pile | The Dark Ancient Evil | Words cancel out | One adjective. Make it count. |
| Vague Abstraction | Destiny's Path | Means nothing | What's the specific destiny? Name it. |
| Too Long | 6+ words | Loses punch | Compress. |
| Requires Explanation | Made-up words | No hook if no recognition | Ground in something known. |

**Test:** Cover the paragraph. Read only the title. Does it break, reveal, or reframe something? If the title just names a subject and the paragraph does the actual work, the title fails. Retitle.

## Anti-Patterns

| Don't | Why |
|-------|-----|
| Remove the IP name from titles when input is known IP | The IP name is the highest-recognition element you have. Abstractions throw away free audience equity. |
| Title a spark with the perspective name | "THE IMMUNE RESPONSE" is not a title. "THE KIDS WHO DON'T BELIEVE" is. |
| Use [IP]'s [Abstract Noun] as a title | "Superman's Shame" is not a title. Find the shame. Name it. |
| Over-develop sparks | That's 2-WORLDS. Volume here. |
| Filter too aggressively | Let the user kill things. Show range. |
| Generate variations instead of divergent ideas | Each spark is a different world, not a remix. |
| Cluster in one perspective family | Cycle through all families. Force unfamiliar territory. |
| Explain why a spark is good | The title and paragraph work or they don't. |
| Show perspective tags | Perspectives are internal machinery. Never visible. |
| Chase stock imagery in titles | "Rise of the Kingdom" could be anything. No authorial voice. |
