# 1-IDEA MODIFIERS

Toggleable constraints for 1-IDEAS generation. Each modifier locks one axis. Multiple stack. Load alongside `1-ideas.md`. Modifiers override the corresponding default behavior; everything else runs normally.

---

## Violation Mode

Lock generation to **Promise Break only**. Every spark uses the Promise Break title move. No exceptions. 

---

## Satiraverse

Lock tone to Spacecadet **satiraverse register**. 

---

## Anti-Taste

**Invert the taste filter.** Every PASS criterion becomes a FAIL. Every FAIL criterion becomes a requirement.

---

## Emotional Registers

Lock each spark to a **target audience gut-reaction**. The emotion fires first — perspective family and title move are reverse-engineered to produce it. Use one register per spark, or stack with Contrast Mode (two registers simultaneously). Tag provenance with `#emotion([CODE])`.

| Code | Emotion | Generation Bias | Watch Out |
|------|---------|-----------------|-----------|
| **WOW** | Inspired + Awe | Scale, transcendence, cosmic time, the sublime | Beautiful dead-ends — pair with HMM or NAH to add tension |
| **NAH** | Disbelief | Inversion, revelation, reframing what everyone assumed | Sharpest titles but can flatten into "actually…" contrarianism |
| **HMM** | Intrigued + Confused | Mystery, paradox, the uncanny, things that almost make sense | Most franchise-generative — every HMM spark is a mystery box |
| **NSFW** | Surprised + Taboo | Transgression, broken social contracts, structural discomfort | One wrong line = edgelord. Taboo must be systemic, not gratuitous |
| **LOL** | Funny | Absurdity, bathos, mundane colliding with mythic | Hardest to keep non-derivative. Best LOLs find comedy in systems, not situations |
| **WTF** | Annoyed | Bureaucracy, Kafkaesque friction, infuriating mundanity | Every WTF implies infrastructure — Kafka's waiting room |
| **UGH** | Disgusted | Moral rot, complicity, the machine behind the myth | Deepest world-builder — disgust requires systems, not moments. Kafka's boss |

**Contrast Mode** — force two registers on one spark. Potent pairs: LOL+UGH (dark comedy), WOW+NSFW (sublime transgression), NAH+HMM (disbelief deepening into mystery), WTF+LOL (absurdist bureaucracy).
