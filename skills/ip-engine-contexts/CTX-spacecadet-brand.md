# Spacecadet Brand Calibration

Amplify Spacecadet DNA in any IP concept. Generative, not gatekeeping.

**Deep reference:** For speculative technology seeds that fuel world-building, consult [references/speculative-tech-seeds/SEEDS.md](references/speculative-tech-seeds/SEEDS.md).

---

## Purpose

Take any IP concept and show how to make it more Spacecadet by amplifying its presence across four dimensions. This context doesn't reject ideas — it translates them into Spacecadet's creative DNA.

---

## The Four Dimensions

Spacecadet operates across two axes:

| | **Space** | **Spacey** |
|---|---|---|
| **Definition** | Sci-Fi infrastructure | Surreal + Spiritual texture |
| **Feel** | Speculative, futuristic, technological | Dream-like, consciousness-expanding, mythic |

These combine with **Satiraverse** (cultural critique, dark humor, irreverence) to create the full Spacecadet palette.

### Dimension 1: Sci-Fi (Space)

**Territory:** Speculative technology, space exploration, futurism, cyberpunk, parallel realities

**Keywords:** Science fiction, speculative futures, futurism, futuristic technology, cyberpunk, moonshots, astrophysics, space exploration, multiverse, parallel universes, time travel, aliens, disruption in time and space

**Reference Feel:** Blade Runner, Dune, The Matrix, Interstellar, Black Mirror

**Amplification Questions:**
- What technology or physics rule shapes this world?
- What speculative infrastructure exists?
- What if time, space, or reality worked differently here?
- What system is everyone plugged into?

**Seed Integration:** Load `references/speculative-tech-seeds/` files matching the IP's thematic territory. Use seeds as evolution fuel, not as gadgets.

### Dimension 2: Surreal

**Territory:** Dream logic, altered states, visual strangeness, magic realism, phenomena

**Keywords:** Surrealism, magic realism, dreams, illusions, visions, phenomena, psychedelics, mind altering, urban surrealism (city as sentient), loops, impossible geometry, reality glitches

**Reference Feel:** EEAAO

**Amplification Questions:**
- What would this look like if logic stopped applying?
- What sensory experience defines this world?
- What seems normal here that shouldn't be?
- What's the visual signature that marks this as surreal?

### Dimension 3: Spiritual (Spacey)

**Territory:** Consciousness, mysticism, mythology, meaning, transcendence

**Keywords:** Metaphysics, spiritual movements, eastern religions, mysticism, divination, consciousness, utopia, magic, mythology, symbolism, sky gods, phenomena, sacred objects, solarpunk as spiritual technology

**Reference Feel:** 2001, Arrival, Tree of Life, Studio Ghibli, Jodorowsky

**Amplification Questions:**
- What does this world believe about consciousness?
- What myth does everyone carry?
- What sacred question haunts this place?
- What would enlightenment look like here?

### Dimension 4: Satiraverse

**Territory:** Cultural critique, dark humor, irreverence, systems exposed, subversion

**Keywords:** Sharp cultural commentary with teeth, the rules changing mid-game, absurdism that's actually about something

**Reference Feel:** Rick and Morty, Sorry to Bother You, Nathan for You, MSCHF

**Amplification Questions:**
- What is this actually about? (capitalism, desire, control, identity)
- What system is being exposed?
- Where's the dark humor?
- What would the MSCHF version of this be?
- What truth is being smuggled in through absurdity?

## The Spacecadet Sweet Spot

There is no single sweet spot. All configurations are valid:

| Configuration | Example | Feel |
|---------------|---------|------|
| **All Four** | Rick and Morty | Maximum Spacecadet |
| **Sci-Fi + Satiraverse** | Black Mirror | Sharp speculative critique |
| **Surreal + Satiraverse** | Sorry to Bother You | Social surrealism with teeth |
| **Surreal + Spiritual** | EEAAO | Cosmic family drama |
| **Sci-Fi + Spiritual** | Arrival, Interstellar | Awe-forward speculation |

**Minimum Spacecadet:** At least 2 dimensions present, executed with intention.

## Workflow

### Step 1: Dimension Presence Map

For the input concept, identify which dimensions are already present and how strong:

| Dimension | Present? | Strength (1-10) | Current Expression |
|-----------|----------|-----------------|-------------------|
| Sci-Fi | | | |
| Surreal | | | |
| Spiritual | | | |
| Satiraverse | | | |

### Step 2: Identify What's Working

Before amplifying, name what makes the concept good now. **Preserve this.**

### Step 3: Amplification Suggestions

For each dimension that could be stronger, provide specific amplification options:

> **Dimension: [X]**
> **Current Strength:** [1-10]
> **Amplification Options:**
> 1. [Specific suggestion that adds this dimension WITHOUT losing what's working]
> 2. [Alternative approach]
> 3. [Third option]
>
> **Execution Note:** [How to integrate this without overwhelming the core]

### Step 4: Execution Translation

Show what the amplified version looks, feels, sounds like. Be specific about visual language, tonal register, world texture, and key scenes or moments that demonstrate the amplification.

**Critical:** The execution translation should ENHANCE the original, not replace it.

### Step 5: Reference Anchors

Provide 2-3 references from the taste profile that hit a similar dimension profile. These help calibrate execution.

### Transformation Gates

Every seed must pass all four before becoming a Central Premise:

| Gate | Test |
|------|------|
| **Load-Bearing** | Does this tech define how the world works, not just decorate it? |
| **Unrecognizable** | Would the original author fail to recognize their concept? |
| **Conflict-Generating** | Does this tech create structural tension (scarcity, inequality, paradox)? |
| **Multi-System** | Does this tech ripple into economy, governance, identity, or culture? |

### Evolution Moves

| Move | Method | Example |
|------|--------|---------|
| **Scale** | Gadget → infrastructure | Neural Lace → all thought is networked |
| **Invert** | Flip the premise | Teleportation → you arrive wrong every time |
| **Combine** | Layer 2-3 seeds | Flesh Putty + Nerve Machine → body is currency, pain is law |
| **Weaponize** | Who controls it? | Memory editing → who owns your past? |
| **Democratize** | Everyone has it | Precognition → no one can be surprised |

**Anti-Patterns:** Tech as easter egg or gadget. Naming or citing source seeds. One tech per world (layer 2-3 as infrastructure). Loading more than 2 seed files per session.

## Quality Gates

| Gate | Test |
|------|------|
| **Preservation** | Did the original's core energy survive? |
| **Integration** | Do the amplified dimensions feel native, not bolted on? |
| **Taste** | Does it pass Daniel's Taste Profile filter? |
| **Specificity** | Are the suggestions concrete enough to execute? |
| **Range** | Did you offer options, not just one "correct" answer? |

## Anti-Patterns

| Don't | Why |
|-------|-----|
| Replace core energy with generic Spacecadet texture | The original spark matters — amplify, don't overwrite |
| Add dimensions that fight the concept | Not everything needs all four; sometimes 2 is enough |
| Make it too earnest | Satiraverse requires teeth; don't sand off the edges |
| Explain the dimensions to the audience | Spacecadet texture is felt, not narrated |
| Lose the humor | If the original was funny, the amplified version should be funnier |

## Tone Constraints (Always Apply)

- Not tragic (no misery as the point)
- Not nihilistic (no "nothing matters")
- Not ironic (no emotional cowardice)
- Hopeful through agency and craft, not cheap optimism
- TikTok x EEAAO is the signature style
- A24 of sci-fi + speculative futures + fantasies (Not MCU)

## IP Engine Integration

The Spacecadet Brand context is most potent at:
- **Stage 1 (Ideas)** — Calibrate every concept for minimum 2 dimensions
- **Stage 2 (Worlds)** — Tech seeds feed directly into world infrastructure
- **Stage 3 (Renders)** — Dimension profile drives visual language and art direction
- **Stage 4 (Scenes/Transmissions)** — Brand dimensions shape Transmission mode selection

Combines with:
- **+ Taste Profile**: All amplification must pass the taste filter
- **+ Alien**: Alien dial amplifies how far dimensions push
