# Anchor Library — Reference Index

Browsable, searchable catalog of all available reference anchors. Used by the Session Config UI to populate the anchor picker. Users can also type custom entries not in this list.

Each entry has a name, category, and suggested take/leave — the user can override the take/leave with their own.
