# 2A-CORE

Stage 1 of world expansion. The spark becomes a world with an identity.

---

## Integration

- **Load:** `daniel-taste-profile/SKILL.md` → PASS/FAIL criteria + reference tags (REQUIRED)
- **Reference:** `world-references.md` → Myth dimension, Belief Gate, Sacred Question benchmarks (REQUIRED)
- **Reference:** `spacecadet-brand/SKILL.md` → brand dimensions at ~25% weight. Light reference for territory, not a filter. (OPTIONAL)

---

## Output Calibration

Each direction should be scannable and comparable side-by-side. Target lengths:

- **Sacred Question:** 1-2 sentences.
- **World Premise:** 2-3 sentences. 
- **Tension:** 1-2 sentences.
- **Allegory:** 1-2 sentences.
- **Myth:** 2-3 sentences. 
- **Rules:** 3-5 rows.
- **Voice & Tone:** 2-3 sentences.

Total per direction: ~250-400 words. Over 400 = cut before presenting.

---

## Generation Pipeline

**Generate 5-7** core identities from the spark internally. Each must explore a different allegorical root — not the same theme with different costumes.

**Filter** all through the Infrastructure Check (below). Kill any that fail 2+ questions.

**Integrate** the best cutting room floor material into the surviving directions before presenting them. Survivors should arrive already enriched — absorb adjacent concepts, useful fragments from killed directions, and enriching ideas into the 2 winners.

**Present 2** divergent survivors. They must differ in what the world is *about* (allegory), not just setting or aesthetic.

**Cutting Room Floor** shows only what wasn't integrated — leftovers, roads not taken, ideas that didn't fit either survivor but are worth remembering.

---

## Spark Type Awareness

**If IP-Referenced or Hybrid:** The source IP's DNA must be physically present in the output — not just thematically echoed. Build FROM the IP's bones. The world premise transforms source material into the impossible element. It doesn't replace it.

Actively identify and integrate:

- **Named characters or archetypes** — transformed, not discarded (Ken becomes *something*, not nothing)
- **Iconic settings** — reinterpreted as world locations, not metaphors (the Dream House is a place)
- **Signature objects** — the source IP's artifacts exist as world artifacts (the box, the accessories, the packaging)
- **Cultural language** — taglines, slogans, marketing copy become scripture, propaganda, or law ("You can be anything" is the world's founding promise or its cruelest lie)
- **Visual DNA** — color, material, proportion (pink means something here; plastic means something here)
- **Real-world origin** — creation story, creator, year of origin become mythology (the factory is the temple; the creator is the god or the first sinner; the year is Year Zero)

## Core Identity (per direction)

Seven components. Each one is DNA — it informs everything built in Stage 2 and Stage 3.

### Sacred Question
One question that contains the entire franchise. The question the world keeps asking and can never fully answer.

### World Premise

1-2 sentences. Hard cap. What is true here that isn't true in ours? State the premise, not the mechanism. If you're explaining HOW it works, you've crossed into Stage 2 infrastructure.

**IP-Referenced:** Push the source IP's existing logic to an extreme. Don't establish the source — assume the reader knows it. State only what's different.

**No Spacecadet dimension tags in output.**

### Tension
1-2 sentences. The central conflict everyone lives with — structural, not plot. Generates infinite stories because it can't be resolved, only navigated. Should emerge naturally from the world premise.

### Allegory
1 sentence. What is this really about? Name it clearly — specific, not vague.

### Myth
2-3 sentences. One origin event + one haunting consequence. Compress — this is scripture, not backstory. 

**IP-Referenced:** Build from the source IP's real history. Transform facts into mythology in the same sentence — don't establish the fact, then transform it. Fuse them.

**For Hybrid/IP-Referenced sparks:** Build the myth FROM the source IP's real history. 

### Rules
3-5 rules with consequences and interlocking connections. Rules should codify how the world premise manifests in daily life. Rules must interlock — changing one cascades through others.

| Rule | Consequence | Interlocks With |
|------|------------|-----------------|

### Voice & Tone

2-3 sentences.

Freeform. This section captures the world's aesthetic identity, emotional texture, and expressive character — how it looks, how it sounds, how it *talks*.

Don't fill categories. Find the specific details that contain the whole world. One vivid image is worth more than four comprehensive descriptions. Prioritize:

- **Details you can quote** — a phrase, an image, a sensory detail that someone would repeat to describe this world to a friend
- **Aesthetic DNA** — the visual, material, and sonic identity recognizable in a single frame or a single sound
- **Emotional texture** — not what the world is about, but what it feels like to be inside it

## Infrastructure Check (Invisible Filter)

Runs internally on all 5-7 directions. This checks whether the *premise* generates enough world to sustain franchise — not whether the premise is speculative enough. This is how we get from 5-7 to 2.

| Question | What It Tests |
|----------|--------------|
| Can I imagine 3+ distinct regions? | Geographic variety → inhabitable world |
| Can I imagine 4+ factions with incompatible worldviews? | Political complexity → structural conflict |
| Can I imagine conflicts independent of the signature mechanic? | Independence → not mechanic-dependent |
| Can I imagine 3+ different stories in this world? | Story variety → franchise potential |
| Can I imagine what a game, series, AND short-form version look like? | Format nativity → Stage 3 viability |

**2+ failures = kill.** Survivors with 1 weakness get an inline ⚠ flag when presented.

---

## IP DNA Gate (Hybrid and IP-Referenced Only)

Runs silently on all surviving directions after the Infrastructure Check. Only applies when Spark Type is Hybrid or IP-Referenced.

| Check | Test |
|-------|------|
| **5-Second Recognition** | Would a fan of the source IP recognize this world as connected within 5 seconds of reading? |
| **Material Present** | Are source IP characters, settings, objects, OR cultural language physically present — not just thematically echoed? |
| **Swap Test** | Could you replace the source IP with a different one and get the same world? If yes → fail. |

**Any fail = rewrite the direction with source IP bones visible.** The collision between the familiar and the strange IS the creative work. If the familiar is gone, there's no collision.

---

## Reference Check (Invisible)

After filtering to 2 survivors, silently benchmark each against `world-references.md`:

- **Myth dimension:** Does the Sacred Question + Myth have weight comparable to reference IPs? (Dune, Star Wars benchmarks)
- **Belief Gate:** Are rules consistent? Does the world cheat?

If either is weak, flag inline with the presentation. Don't display as a gate table.
