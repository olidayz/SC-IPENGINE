# Cultural Instrument Library — Reference

A taxonomy of 128+ recognizable media formats. The audience recognizes the CONTAINER instantly (oh, this is a nature doc / this is a PSA / this is a confessional) — that recognition is free engagement. The IP CONTENT inside the container is the payload. Format is the Trojan horse.

**Usage:** This file is a reference. During Invocation 2, the skill scans the world's media entities, then selects 25-35 instruments from this library that match those entities. Selection is ENTITY-DRIVEN — entity first, instrument second.

## Original Instrument Generation

The 128 above are the FLOOR. Four approaches to creating instruments that don't exist yet:

### Collision
Fuse two existing instruments. The tension between formats creates novelty. Therapy Session × Cooking Show. Security Cam × ASMR. News Broadcast × Lullaby. The fusion must feel inevitable in retrospect.

### Platform-Native
Exploit specific platform mechanics. Duet-chain narratives, poll-as-plot-device, loop-mystery, AR-filter-as-character. Formats that only work because of how the platform functions.

### World-Native
Media that exists INSIDE the IP world. Not us depicting the world — the world's own entertainment, news, propaganda, education, religion, advertising. Present it as if it's real. The format becomes proof the civilization exists.

### Genre Inversion
Take a known format and break its contract with the viewer. Wholesome format + horrific content. Urgent format + mundane content. Instructional format + impossible task. Confessional format + no vulnerability (clearly performing). The subversion IS the commentary.
